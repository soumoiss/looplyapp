Looply

Sobre o projeto

Este repositório será utilizado para a futura reconstrução, melhoria e manutenção do aplicativo Looply.

O objetivo é desenvolver uma implementação organizada, segura, confiável e bem testada, preservando integralmente as funcionalidades, as regras de negócio e o comportamento esperado da aplicação existente.

Objetivos

- Analisar e documentar a implementação atual.
- Identificar e corrigir bugs, inconsistências e vulnerabilidades.
- Melhorar a qualidade, a organização e a manutenção do código.
- Implementar testes para validar as funcionalidades e prevenir regressões.
- Preservar os fluxos de usuário e as regras de negócio existentes.
- Validar as integrações antes de qualquer alteração em produção.

Infraestrutura existente

A reconstrução deverá preservar os serviços já utilizados pelo aplicativo:

- GitHub: este repositório será o destino do novo código.
- Supabase: manter o projeto existente, seus dados, autenticação e configurações.
- Vercel: manter o projeto existente, seus domínios, variáveis de ambiente e configurações de implantação, ajustando a conexão com o novo repositório somente quando autorizado e necessário.

Nenhuma credencial, chave privada, senha ou segredo deverá ser armazenado neste arquivo ou enviado ao controle de versão.

Regras fundamentais

1. O aplicativo existente é a referência oficial de comportamento.
2. Nenhuma funcionalidade ou regra de negócio deverá ser removida ou alterada arbitrariamente.
3. A implementação deverá ser precedida por uma análise técnica e um plano de execução.
4. A integridade dos dados e a segurança das integrações são prioridades.
5. As alterações deverão ser testadas antes de serem consideradas concluídas.
6. O repositório original deverá ser preservado como referência e possibilidade de recuperação.
7. Nenhuma alteração em produção deverá ser realizada sem autorização explícita.

Estado atual

Este repositório está sendo preparado para receber a futura implementação do Looply.

A análise do projeto original, o planejamento da reconstrução e a autorização para iniciar o desenvolvimento deverão ocorrer antes da implementação de funcionalidades.

Status: preparação inicial do repositório.

Importante: a criação deste README não autoriza modificações no aplicativo, no Supabase, no Vercel ou em qualquer infraestrutura existente.
